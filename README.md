# I Am Scientist — Landing Page Clone

A pixel-focused clone of the [iamscientist.ai](https://iamscientist.ai/) landing page, built as part of an internship assignment. Recreates the full homepage — layout, typography, colors, spacing, and responsiveness — using Next.js and Tailwind CSS.

## 🔗 Links

- **Live Demo:** [iamscientist-clone-gold.vercel.app](https://iamscientist-clone-gold.vercel.app)
- **Original Site:** [iamscientist.ai](https://iamscientist.ai/)

## 🛠️ Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Deployment:** Vercel

## 📋 Sections Implemented

1. Navbar (with mobile hamburger menu)
2. Hero (auto-rotating headline slider)
3. Countdown timer bar
4. Announcements (General / Contest / Course)
5. CTA banner
6. Courses grid
7. Magic Tools grid
8. Country Partners
9. Prizes (Silver / Gold / Bronze)
10. Merit Awards banner
11. Student winners carousel
12. FAQ accordion
13. Image gallery
14. Newsletter subscribe
15. Footer

## 🚀 Getting Started

Clone the repo and install dependencies:

```bash
git clone https://github.com/awaiszamir244-svg/iamscientist-clone.git
cd iamscientist-clone
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📱 Responsiveness

Built and tested across mobile, tablet, and desktop breakpoints using Tailwind's responsive utilities.

## 📁 Project Structure

src/app/

layout.tsx
